| [0029](0029-turned-text.md) | Text under a transform that turns, slants or scales: glyphs rasterised from their outlines for the transform, with quarter-pixel pen fractions on both axes, and drawn in screen space (`PushScreenSpace`); while the transform changes from frame to frame the renderer resamples upright glyphs as before and one more frame is asked for | Accepted |
| [0030](0030-launcher-icons-flattened-in-the-encoded-space.md) | The icon generator flattens transparency on sRGB-encoded values, as the renderer and the launchers composite (0023); resizing stays in linear light. Amends a detail of 0020 | Accepted |
| [0031](0031-shaping-cache-without-colour.md) | The shaping cache is keyed on everything but colour; a glyph takes its span's colour when drawn, so fading rich text is shaped once | Accepted |
| [0032](0032-accessibility.md) | Accessibility: a semantics tree derived from the painted frame (defaults, merge rules, modifiers), built only while assistive technology is on, sent to the hosts as diffs in one buffer; a virtual view hierarchy on Android, accessibility elements on iOS; a checker and a test API | Accepted; not tried with a screen reader |
| [0033](0033-radial-gradients.md) | Radial gradients (circle or ellipse, any centre and size, any number of stops) as a quad fill, one instance per pair of neighbouring stops with half-open bands so segments never overlap; the instance grows from 144 to 160 bytes by one general `vec4`; `Radial` in the UI layer with CSS's shape, position and size keywords, stacked like a CSS `background` list | Accepted |
| [0034](0034-blur-of-a-box-background.md) | `filter: blur` of a box's background evaluated per pixel with no blur pass: a solid box as its own shadow (exact), a radial gradient by a 6 x 6 Gauss-Hermite quadrature of the unblurred picture (about 1% where the gradient fades out inside its box); arbitrary content not blurred | Accepted |
| [0035](0035-inner-shadows-and-several-shadows.md) | Inner (`inset`) shadows as one more quad kind, with offset, blur and spread; several shadows on one box in CSS order | Accepted |
| [0036](0036-a-radius-per-corner.md) | A radius per corner for solid and bordered rectangles; gradients, dashes and clips keep the single radius | Accepted |
| [0037](0037-scroll-views-that-scroll-sideways.md) | Scroll views that scroll sideways: a row that offers its children unlimited width, the same per-identity scroll state along x, and a drag given to the scroll view that runs the finger's way | Accepted |
