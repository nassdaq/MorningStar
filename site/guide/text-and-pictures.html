Text, fonts and pictures

Text

A text takes a step of the theme's type scale, and any property can be overridden.

col![
    text("TSh 1,250,000").display(),
    text("Repairs").title(),
    text("Waiting for parts").headline(),
    text("The screen was replaced and tested with the customer."),
    text("SAVE").label(),
    text("Updated 08:02").caption().muted(),
]
.gap(8.0)
RoleDefault sizeWeightUsed for
display34 dpBoldThe one big number or word on a screen
title24 dpBoldA screen title
headline17 dpSemiboldA section or card heading
body15 dpRegularRunning text. The default
label14 dpSemiboldButtons, tabs, field labels
caption12 dpRegularMetadata, timestamps, hints
col![
    text("Order 1042")
        .size(22.0)
        .semibold()
        .letter_spacing(-0.3)
        .line_height_dp(28.0),
    // One text, three styles: spans share the line breaking.
    Text::rich([
        span("By continuing you accept the "),
        span("terms of service").bold().color(ThemeColor::Primary),
        span("."),
    ])
    .muted()
    .fill_width(),
    // Digits on a common width, so a column of amounts lines up.
    text("12,400.00").tabular_nums(),
    // At most two lines; the rest is cut off.
    text("A long note that the customer wrote when the phone was handed in.")
        .max_lines(2)
        .fill_width(),
]
.gap(8.0)
.fill_width()

Text wraps at the width of its box, so a text that should wrap needs a width: usually .fill_width(). Scripts that run right to left, such as Arabic, are shaped and ordered correctly within the text's own box.

Every method is listed under Text.

Fonts

An app bundles its fonts and adds them at setup. Nothing is drawn from a system font unless the app asks for the system's fonts.

fn setup(&mut self, setup: &mut Setup<'_>) {
    setup.add_font(include_bytes!("../assets/fonts/Inter-Regular.ttf"));
    setup.add_font(include_bytes!("../assets/fonts/SpaceGrotesk-Bold.ttf"));
}

A family is chosen per text with .family("Space Grotesk"), or for the whole app in the theme: Fonts::new(body, heading) sets the family for body roles and for heading roles. If the family has no italic file, italic is synthesised by slanting.

Icons

An icon is one-colour vector artwork that takes its colour where it is drawn.

/// One-colour markup in the source: the path of a 24 by 24 icon.
const CHECK: VectorIcon = VectorIcon::stroked("M5 12l5 5L20 7");

/// An icon alone, an icon on a round tile, and a glyph as a stand-in.
pub fn icons<M: 'static>() -> Element<M> {
    row![
        icon(CHECK).color(ThemeColor::Success),
        Icon::vector(CHECK)
            .size(40.0)
            .round()
            .background(ThemeColor::PrimaryContainer)
            .color(ThemeColor::Primary),
        Icon::new("?").size(40.0),
    ]
    .gap(12.0)
    .cross_align(CrossAlign::Center)
    .into()
}

For icons kept as files, load them as SVG (below) and draw them with Icon::svg(asset.get()). A file that uses a single ink is tinted like any other icon.

SVG files

SVG is loaded at run time by a strict reader written for the purpose. It supports a static subset: shapes, groups, transforms, clips, gradients, dashes and currentColor. Anything else is an error that names the line, so a file either draws as designed or is refused.

/// An SVG file of the app, parsed once, the first time it is drawn.
static LOGO: SvgAsset = SvgAsset::new(
    r##"<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24">
        <circle cx="12" cy="12" r="10" fill="#E3AE3A"/>
        <path d="M7 12l3.5 3.5L17 9" fill="none" stroke="#141005" stroke-width="2"/>
    </svg>"##,
);

/// The file as a picture, in its own colours.
pub fn logo<M: 'static>() -> Element<M> {
    Picture::svg(LOGO.get()).width(96.0).height(96.0).into()
}

Check a file before using it: morningstar-svg art.svg out.png --scale 3 renders it exactly as an app would. See Tools and ADR 0027.

Images

Images come from PNG data or raw pixels, added once at setup. A Picture draws one with a fit, a corner radius and an optional tint; an Avatar crops one to a circle and falls back to initials.

/// An app with one photograph, decoded once at setup.
#[derive(Default)]
pub struct Gallery {
    photo: Option<Image>,
}

impl Application for Gallery {
    type Message = ();

    fn setup(&mut self, setup: &mut Setup<'_>) {
        // Four pixels stand in for `include_bytes!("../assets/photo.png")`
        // with `setup.add_image_png(..)`.
        let pixels = [255, 255, 255, 255].repeat(4);
        self.photo = setup.add_image_rgba8(2, 2, &pixels).ok();
    }

    fn view(&self) -> Element<()> {
        match self.photo {
            // Cropped to fill a rounded 16:9 box.
            Some(photo) => Picture::new(photo)
                .fit(ImageFit::Cover)
                .radius(16.0)
                .fill_width()
                .aspect_ratio(16.0 / 9.0)
                .into(),
            // An avatar falls back to initials when there is no image.
            None => Avatar::new("Amina Juma").image_maybe(self.photo).into(),
        }
    }

    fn update(&mut self, _message: ()) {}
}

Only PNG is decoded. The Barua Talk example keeps its photographs as JPEG for the design and converts them to PNG with a small script, examples/barua-talk/design/prepare-images.py.

Each image is its own texture and splits the frame's draw call (ADR 0014), which is worth knowing for a long list of photographs.

Turned text, outlines and shadows

A widget can be drawn through a transform (.rotate(degrees), .transform(..)), and text under a transform is rasterised for it, so turned text stays sharp. Text::shadow draws a hard shadow and Text::outline a stroke around the letters. Building screens has worked examples of each.
