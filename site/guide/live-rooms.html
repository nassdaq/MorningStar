Guide/Core concepts/Live rooms

Live rooms

A live room carries sound, pictures and small data messages between the people in it. On Android it is LiveKit's client, behind the same effects interface as every other service. The app's server hands out a ticket (an address and a token); the app joins with it.

Live rooms are opt-in per app, because LiveKit and WebRTC add about 20 MB to an APK. An app that does not ask for them carries none of the code. See Opt-in services.

[package.metadata.morningstar]
services = ["live", "live-video"]

Joining, and following the room

A join is answered more than once: one message per event until a final one. Disconnected and Failed are final.

fn update(&mut self, message: Message) {
    match message {
        Message::Ticket { url, token } => self.start.push(Start::Join { url, token }),
        Message::Mute(muted) => {
            self.muted = muted;
            self.start.push(Start::Microphone(!muted));
        }
        Message::HangUp => self.start.push(Start::Leave),
        // One message per event, until a final one.
        Message::Live(event) => match event {
            LiveEvent::Connected => {
                self.connected = true;
                self.status = "Sound is live.".to_owned();
            }
            LiveEvent::VideoStarted(stream) if !stream.local => {
                self.picture = Some(stream.track);
            }
            LiveEvent::VideoStopped(stream) if Some(stream.track) == self.picture => {
                self.picture = None;
            }
            LiveEvent::Reconnecting => self.status = "Reconnecting...".to_owned(),
            LiveEvent::Reconnected => self.status = "Sound is live.".to_owned(),
            // Final: the room is over, whoever ended it.
            LiveEvent::Disconnected(_) => {
                self.connected = false;
                self.picture = None;
                self.status = "The call ended.".to_owned();
            }
            // Final: it never started, or could not go on.
            LiveEvent::Failed(LiveError::PermissionDenied) => {
                self.status = "The microphone is not allowed.".to_owned();
            }
            LiveEvent::Failed(error) => self.status = format!("No sound: {error}."),
            _ => {}
        },
    }
}

fn effects(&mut self, out: &mut Effects<Message>) {
    for start in self.start.drain(..) {
        match start {
            // The ticket comes from the app's server, never from the
            // app: a server holds the key that mints it.
            Start::Join { url, token } => out.join_live(
                LiveJoin::new(url, token).microphone(true).camera(true),
                Message::Live,
            ),
            Start::Microphone(live) => out.set_live_microphone(live),
            Start::Leave => out.leave_live(),
        }
    }
}
VariantMeaning
ConnectedThe room is joined: sound from the others plays, and the microphone is heard by them unless the room was joined muted.
ParticipantJoinedSomeone is in the room: they were there already, or have come in.
ParticipantLeftSomeone left. Their identity.
SpeakingWho is speaking now, loudest first, by identity (this device's own person included, under the identity of its ticket); empty when nobody is.
ReconnectingThe connection dropped and is being made again; nothing is heard meanwhile.
ReconnectedThe connection is back.
VideoStartedA video has started: someone's camera or shared screen, this device's own included.
VideoStoppedThat video is over: its owner turned it off, or left.
MediaFailedThis device's camera or screen could not be turned on: the user refused it (LiveError::PermissionDenied), the app was built without it (LiveError::Unsupported), or it failed.
DataSomeone sent a message to the room.
AudioRoutesWhere the sound can go and where it goes now (ADR 0042): sent once the room is connected and again whenever either changes, a headset connecting in the middle of a call included.
DisconnectedThe room is over for this device, for the reason given.
FailedThe room could not be joined, or broke.

One room at a time. Joining a second room leaves the first, which ends with Disconnected(Replaced).

Pictures

A camera or a shared screen arrives as a VideoStarted event with a VideoTrack. The app draws the track with LiveVideo; the frames themselves never pass through the application.

fn view(&self) -> Element<Message> {
    let picture: Element<Message> = match self.picture {
        // Frames never pass through the application: it draws the
        // track, and the host fills it in.
        Some(track) => LiveVideo::new(track).fit(ImageFit::Cover).fill().into(),
        None => Container::empty()
            .background(ThemeColor::Surface)
            .fill()
            .into(),
    };
    stack![
        picture,
        col![
            text(self.status.clone()).color(ThemeColor::OnPrimary),
            Button::new(if self.muted { "Unmute" } else { "Mute" })
                .secondary()
                .on_press(Message::Mute(!self.muted)),
            Button::new("Hang up")
                .destructive()
                .on_press(Message::HangUp),
        ]
        .gap(12.0)
        .padding(20.0)
        .place(Alignment::BOTTOM_CENTER),
    ]
    .fill()
    .into()
}

LiveVideo draws nothing until a frame exists, so whatever is stacked underneath is the placeholder. Camera pictures need the live-video service; sharing this phone's screen needs live-screen.

When a room ends

A live room holds the microphone open, so nothing may leave one connected by accident.

VariantMeaning
LeftThe application left it.
ReplacedThe application joined another room: there is one at a time.
HiddenThe app left the screen.
HungUpThe user ended it from the notification of a room that was going on in the background (ADR 0042).
EndedThe other side ended it: the room was closed, this person was removed, or the same ticket joined from somewhere else.
LostThe connection was lost and could not be made again.

By default a room is left when the app leaves the screen: Home, another app, or the screen locking. Two things change that:

  • A shared screen. A room in which this phone's screen is being shared continues behind other apps, since sharing is pointless otherwise. The user agreed in a system dialog and a notification shows it.
  • live-background. An app that declares this service and joins with LiveJoin::background(LiveBackground::new(title, text)) keeps the call going behind another app or with the screen locked, with an ongoing notification that has a Hang up action.

What has been verified

Everything on this page passes its tests on the development machine, and the Android side compiles and packages. None of it has been confirmed on a phone yet: no sound has been heard and no picture seen through a real room. The iOS host answers every join with Unsupported.

The decisions, with every case a room ends in, are ADR 0038, ADR 0039 and ADR 0042. The Barua Talk example is the app that uses all of it.
