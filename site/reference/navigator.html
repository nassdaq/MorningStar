Navigator, Viewport and ScrollTo

Navigator

The stack of screens as plain application state. Navigation and time is the guide.

MethodWhat it does
new(root: S)A stack holding only root, the first screen.
current() -> &SThe screen on top: the one to show.
current_mut() -> &mut SThe screen on top, mutably (to change the data a screen carries).
root() -> &SThe first screen, at the bottom of the stack.
stack() -> &[S]Every screen, the first at the bottom, the current one last.
depth() -> usizeHow many screens are on the stack; at least 1.
can_pop() -> boolTrue if there is a screen to go back to.
push(screen: S)Shows screen, keeping the current one under it to come back to.
replace(screen: S)Shows screen in place of the current one
pop() -> Option<S>Goes back one screen and returns the one that was showing, or None, changing nothing, on the first screen.
back() -> boolGoes back one screen; false, changing nothing, on the first.
pop_to_root() -> boolGoes back to the first screen, dropping every screen above it.
pop_to(wanted: impl Fn(&S) -> bool) -> boolGoes back to the nearest screen for which wanted is true, dropping the ones above it.
reset(root: S)Starts again: the stack holds only root (after signing out, or when a tab bar switches section).
set(screens: impl IntoIterator<Item = S>) -> boolReplaces the whole stack
last_change() -> NavigationWhat the last change was, for a view that wants to animate it its own way.
transition() -> TransitionThe Transition for the root of the current screen that suits the last change: a pushed screen slides in from the right while the one it covers moves a little to the left and fades; a pop is the same backwards; a replacement cross-fades; and at start there is none.

Viewport

What Application::view_in is given: the screen the view is drawn on, in dp.

MethodWhat it does
width() -> f32Width of the surface in dp.
height() -> f32Height of the surface in dp.
safe_size() -> SizeThe size, in dp, of what is neither under system bars nor under the keyboard: the room a SafeArea at the root gives its child.
keyboard_visible() -> boolTrue while the soft keyboard covers part of the surface.
has_focus() -> boolTrue if a TextInput had focus when this frame began.
is_focused(id: impl Hash) -> boolTrue if the TextInput with this explicit .id(..) had focus when this frame began.
measure(text: &Text) -> SizeThe size, in dp, text has on one line: its style, weight, family, letter spacing and spans taken into account, exactly as the layout will measure it (width in whole pixels).
measure_wrapped(text: &Text, max_width: f32) -> SizeThe size, in dp, text has when wrapped at max_width dp.
line_count(text: &Text, max_width: f32) -> u32How many lines text takes when wrapped at max_width dp (not bounded by its max_lines).

Text is measured exactly as layout will measure it, so a view can choose between two layouts instead of guessing from a character count.

ScrollTo

A request to move a scroll view, queued with out.scroll(..) and carried out in the next frame, after its layout.

MethodWhat it does
top(scroll_view: impl Hash)The top of the scroll view with this .id(..).
end(scroll_view: impl Hash)The end of the scroll view with this .id(..): its last content at the bottom of the viewport.
offset(scroll_view: impl Hash, dp: f32)dp from the top of the scroll view with this .id(..), kept within what it can scroll.
reveal(widget: impl Hash)Brings the widget with this .id(..) into view by scrolling the scroll views it is in, the innermost first, each as little as needed; nothing moves if it is already in view.
margin(dp: f32)For reveal: keeps this many dp between the widget and the edges of the viewport.
animated()Glides there (250 ms, easing out) instead of jumping.

Transition

How a widget enters and leaves, for .transition(..).

MethodWhat it does
none()No transition: the widget is simply there, then simply gone.
fade()Fades in and out.
slide(x: f32, y: f32)Slides in from, and back out to, x widths to the right and y heights below where it belongs (its own width and height; negative for left and above).
scale(from: f32)Grows in from, and shrinks out to, from times its size, about its centre, fading as it does.
exit_slide(x: f32, y: f32)Leaves towards x widths and y heights away instead of going back where it came from: a screen that came from the right and leaves to the left.
with_fade()Also fades, in and out.
enter_fade()Also fades in, without fading out.
exit_fade()Also fades out, without fading in.
duration(duration: Duration)How long entering and leaving take (280 ms by default).
easing(easing: Easing)The easing of both (ease-out by default).
