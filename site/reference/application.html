Application

The trait an app implements. Only update and the Message type are required.

pub trait Application: Send + 'static {
    type Message: Clone + Send + 'static;

    fn setup(&mut self, setup: &mut Setup<'_>) {}
    fn theme(&self) -> Theme { Theme::LIGHT }
    fn view(&self) -> Element<Self::Message> { Container::empty().into() }
    fn view_in(&self, viewport: &Viewport<'_>) -> Element<Self::Message> { self.view() }
    fn update(&mut self, message: Self::Message);
    fn back(&mut self) -> bool { false }
    fn tick(&self) -> Option<(Duration, Self::Message)> { None }
    fn effects(&mut self, out: &mut Effects<Self::Message>) {}
    fn system_bars(&self) -> Option<SystemBars> { None }
}

Registering

morningstar::app!(Ui::new(MyApp::default()));

Ui runs the application on the runtime; app! makes the crate the native library the host loads. One per crate.

Setup

What setup is given: the place to add fonts and images, and what the phone already knows.

MethodWhat it does
install_id() -> &strAn identifier for this installation of the app: 32 lower-case hexadecimal digits (128 bits).
stored(key: &str) -> Option<&str>The value stored under key on an earlier run (see ServiceRequest::Store), as it was when the app started.
add_font(data: &[u8])Registers a TrueType/OpenType font from its file contents, typically include_bytes!.
has_font_family(name: &str) -> boolTrue if a font of the family called name has been added (names are compared without regard to case).
load_system_fonts()Makes the device's installed fonts available as a last-resort fallback.
add_image_rgba8(width: u32, height: u32, pixels: &[u8]) -> Result<Image, ImageError>Registers an image from decoded pixels; see Frame::add_image_rgba8.
add_image_png(data: &[u8]) -> Result<Image, ImageError>Registers an image from the contents of a PNG file, typically include_bytes!; see Frame::add_image_png.
