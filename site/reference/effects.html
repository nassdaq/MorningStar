Reference/API/Effects

Effects

The queue an application puts its requests on, from Application::effects. Each request that has an answer names the message the answer becomes. Effects and services is the guide.

Every method

MethodWhat it does
http(request: HttpRequest, on_result: impl FnOnce(Result<HttpResponse, HttpError>) -> M + Send + 'static)Makes an HTTP or HTTPS request.
start_recording(on_result: impl FnOnce(Result<(), AudioError>) -> M + Send + 'static)Starts recording from the microphone.
stop_recording(on_result: impl FnOnce(Result<Recording, AudioError>) -> M + Send + 'static)Stops the recording. The message gets it as the bytes of an audio file (audio/mp4: mono AAC in an M4A container) with its length, ready to be the body of a request, or AudioError::NotRecording if none was running.
play(clip: AudioClip, on_finished: impl FnOnce(Result<(), AudioError>) -> M + Send + 'static)Plays a clip (audio/mpeg or audio/mp4), replacing one that is playing.
stop_playback()Stops whatever is playing.
store(key: impl Into<String>, value: impl Into<String>)Keeps value under key between launches, in the app's private storage.
remove(key: impl Into<String>)Forgets the value kept under key.
load(key: impl Into<String>, on_loaded: impl FnOnce(Option<String>) -> M + Send + 'static)Reads the value kept under key
set_clipboard(text: impl Into<String>)Puts plain text on the system clipboard, replacing what is there.
clipboard(on_text: impl FnOnce(Option<String>) -> M + Send + 'static)Reads the system clipboard as plain text
announce(message: impl Into<String>)Has the screen reader say message, when one is running: for something that happened and that nothing on the screen says by itself ("Report ready", "Message sent").
announce_with(message: impl Into<String>, live: Live)As announce, saying how urgent it is
join_live(join: LiveJoin, on_event: impl FnMut(LiveEvent) -> M + Send + 'static)Joins a live room (ADR 0038): a conversation on a media server, where the people in it hear each other.
leave_live()Leaves the live room.
set_live_microphone(live: bool)Opens (true) or mutes the microphone in the live room.
set_live_speaker(on: bool)Sends the live room's sound to the loudspeaker (true) or the earpiece.
send_live_data(topic: impl Into<String>, payload: impl Into<Vec<u8>>, reliable: bool)Sends payload to everyone else in the live room, under topic (ADR 0039): they receive it as LiveEvent::Data.
set_live_camera(on: bool)Turns this device's camera on or off in the live room (ADR 0039).
switch_live_camera()Changes between the front and the back camera.
set_live_screen_share(on: bool)Starts or stops sharing this device's screen with the live room (ADR 0039).
set_live_audio_route(route: LiveAudioRoute)Sends the live room's sound to route (ADR 0042): the earpiece, the loudspeaker, a wired headset or a Bluetooth one.
forget_pending()Gives up on every request made before this call that has not been answered yet: their messages will never arrive.
scroll(to: ScrollTo)Asks a scroll view to move: to its top or end, to an offset, or as far as brings a widget into view; at once or gliding.

HttpRequest

MethodWhat it does
new(method: HttpMethod, url: impl Into<String>)A request with no headers, no body and the default timeout.
get(url: impl Into<String>)A GET request.
post(url: impl Into<String>)A POST request.
put(url: impl Into<String>)A PUT request.
delete(url: impl Into<String>)A DELETE request.
header(name: impl Into<String>, value: impl Into<String>)Adds a header. Carriage returns and line feeds are removed from the name and the value: a header cannot contain them, and removing them here means a value that came from user input cannot add a header of its own.
body(body: impl Into<Vec<u8>>)Sets the body. Say what it is with a Content-Type header.
json_body(json: impl Into<Vec<u8>>)Sets the body to JSON the application has already encoded, with Content-Type: application/json.
timeout(timeout: Duration)Sets the timeout for the whole exchange.
header_value(name: &str) -> Option<&str>The value of the first header called name, compared without regard to case.
Method
HttpMethod::Get, Post, Put, Patch, Delete, HeadThe methods there are

HttpResponse

MethodWhat it does
new(status: u16)A response with this status, no headers and an empty body.
with_header(name: impl Into<String>, value: impl Into<String>)Adds a header.
with_body(body: impl Into<Vec<u8>>)Sets the body.

The status is the public field status.

HttpError

VariantMeaning
OfflineThe server could not be reached: no network, the name did not resolve, or the connection was refused or dropped.
TimeoutThe exchange took longer than the request's timeout.
InvalidUrlThe URL is not an absolute http or https URL.
TooLargeThe response body is larger than MAX_HTTP_RESPONSE_BYTES.
UnsupportedNothing can make requests here: there is no host (a test without a driver, a screenshot tool) or the host is older than this library.
FailedAnything else, described by the platform: a TLS failure, a cleartext request the platform's policy forbids.

AudioError

VariantMeaning
PermissionDeniedThe user has not allowed the microphone.
BusyA recording is already running (for "start"), or the microphone or the audio output is held by something that would not give it up.
UnsupportedNothing can record or play here: there is no host (a test without a driver, a screenshot tool), the host is older than this library, or the device has no microphone.
NotRecording"Stop recording" with no recording to stop.
InterruptedPlayback ended before the clip did: the application stopped it, started another clip, went to the background, or lost the audio output to a phone call.
FailedAnything else, described by the platform.

MethodWhat it does
new(url: impl Into<String>, token: impl Into<String>)Joins with the microphone live, sound in the earpiece, and no speaking reports.
background(notice: LiveBackground)Lets the room go on while the app is not on screen, under this notice (ADR 0042).
camera(on: bool)Whether the camera is on from the start.

MethodWhat it does

LiveEvent

VariantMeaning
ConnectedThe room is joined: sound from the others plays, and the microphone is heard by them unless the room was joined muted.
ParticipantJoinedSomeone is in the room: they were there already, or have come in.
ParticipantLeftSomeone left. Their identity.
SpeakingWho is speaking now, loudest first, by identity (this device's own person included, under the identity of its ticket); empty when nobody is.
ReconnectingThe connection dropped and is being made again; nothing is heard meanwhile.
ReconnectedThe connection is back.
VideoStartedA video has started: someone's camera or shared screen, this device's own included.
VideoStoppedThat video is over: its owner turned it off, or left.
MediaFailedThis device's camera or screen could not be turned on: the user refused it (LiveError::PermissionDenied), the app was built without it (LiveError::Unsupported), or it failed.
DataSomeone sent a message to the room.
AudioRoutesWhere the sound can go and where it goes now (ADR 0042): sent once the room is connected and again whenever either changes, a headset connecting in the middle of a call included.
DisconnectedThe room is over for this device, for the reason given.
FailedThe room could not be joined, or broke.

LiveDisconnect

VariantMeaning
LeftThe application left it.
ReplacedThe application joined another room: there is one at a time.
HiddenThe app left the screen.
HungUpThe user ended it from the notification of a room that was going on in the background (ADR 0042).
EndedThe other side ended it: the room was closed, this person was removed, or the same ticket joined from somewhere else.
LostThe connection was lost and could not be made again.

LiveError

VariantMeaning
PermissionDeniedThe user has not allowed it: the microphone for a join, the camera or the screen in LiveEvent::MediaFailed.
UnsupportedNothing can join a live room here: there is no host (a test without a driver, a screenshot tool), the host is older than this library, the app was built without the live service (it is opt-in, see ADR 0038), or the platform has none yet (iOS).
FailedAnything else, described by the platform: the server refused the ticket, the address is wrong, the network is down.

LiveAudioRoute

VariantMeaning
EarpieceThe speaker at the ear.
SpeakerThe loudspeaker.
