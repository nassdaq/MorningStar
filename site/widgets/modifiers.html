Common modifiers

Every widget has these. They are chained after the widget's own methods, in any order.

Size and position

MethodWhat it does
width(dp: f32)Fixed width in dp.
height(dp: f32)Fixed height in dp.
fill_width()Take the width the parent has left ("fill container").
fill_height()Take the height the parent has left.
fill()Fill both axes.
fill_width_weight(weight: f32)Fill the width with a weight: siblings that fill share the space left in proportion to their weights (flex in Flutter).
fill_height_weight(weight: f32)Fill the height with a weight.
hug_width()As wide as the contents ("hug contents").
hug_height()As tall as the contents.
width_sizing(sizing: Sizing)Sets the horizontal sizing from the layout engine's own type.
height_sizing(sizing: Sizing)Sets the vertical sizing from the layout engine's own type.
min_width(dp: f32)Lower bound on the width in dp, whatever the sizing.
max_width(dp: f32)Upper bound on the width in dp, whatever the sizing.
min_height(dp: f32)Lower bound on the height in dp.
max_height(dp: f32)Upper bound on the height in dp.
aspect_ratio(ratio: f32)Width divided by height.
align_self(align: CrossAlign)Inside a row or column: overrides the parent's cross-axis alignment for this widget.
place(anchor: Alignment)Inside a stack: pins this widget to one of nine anchors, overriding the stack's own alignment.
offset(x: f32, y: f32)Moves the widget by this many dp after layout, without affecting its siblings (a badge overhanging a corner).
transform(transform: Transform)Draws the widget, and everything inside it, through a transform about its own centre, without affecting layout
rotate(degrees: f32)Turns the widget about its centre, clockwise for positive degrees
id(id: impl Hash)Gives the widget an explicit identity.

.size(width, height) is short for a fixed width and height.

Identity

.id(value) gives a widget an explicit identity, which is what scroll positions, focus, presses and animations belong to. The application model says when one is needed.

Motion

MethodWhat it does
opacity(opacity: f32)Draws the widget and everything inside it at this opacity
animate(duration: Duration, easing: Easing)Shows changes of this widget's own properties over duration instead of at once: when a later view gives the same widget (the same identity; give it an .id(..)) a different opacity, transform or offset, solid background colour, or fixed width or height, it is drawn on the way from the old value to the new one.
transition(transition: Transition)How the widget appears in the first frame it is in the tree and disappears in the first frame it is not: see Transition.

See Themes and motion.

Accessibility

MethodWhat it does
semantic_label(label: impl Into<Cow<str>>)What a screen reader calls this widget, instead of the text inside it.
semantic_role(role: Role)What the widget is to a screen reader, when the default (a tappable box is a button, a text is text) is not right
heading()Marks the widget as a heading, which a screen reader's user can jump between.
hint(hint: impl Into<Cow<str>>)What the widget is for, spoken after its label and a pause: "Opens the report".
value(value: impl Into<Cow<str>>)What the widget shows now, spoken after its label: a progress bar's "72 percent", a score's "81 out of 100".
selected(selected: bool)Says whether this is the chosen one among its siblings: the current tab, the picked chip or plan.
checked(checked: bool)Says that this can be ticked and whether it is: a checkbox, a switch.
expanded(expanded: bool)Says that this opens and closes and which it is now.
disabled(disabled: bool)Says that this cannot be operated now.
live(live: Live)Has a screen reader announce what this widget says whenever it changes, without the user going to it: the caller's new line, "Recording…", an error under a field.
exclude_semantics()Hides the widget, and everything inside it, from screen readers: for decoration that would only be noise.
merge_semantics()Makes the widget one stop for a screen reader: the texts inside it are read together as its label, in order.
semantics_group()Makes the widget a container for a screen reader, keeping what is inside it as separate stops: a named region, a group of radio buttons.

On widgets where label and role are not already taken by the text style, the two short names exist as well:

MethodWhat it does
label(label: impl Into<Cow<str>>)What a screen reader calls this widget.
role(role: Role)What the widget is to a screen reader: see semantic_role.

See Accessibility.

Converting messages

Element::map converts the messages a subtree produces, so a view written for one message type can be used inside an app with another.

MethodWhat it does
map<N>(convert: impl Fn(M) -> N + Copy + Send + Sync + 'static) -> Element<N>Converts the messages this subtree produces, so a view written for one message type can be embedded in a parent with another
