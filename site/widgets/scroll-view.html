ScrollView

A viewport around content that is taller, or wider, than the space it has.

let mut list = Column::new().gap(12.0).padding(20.0).fill_width();
for (index, row) in rows.into_iter().enumerate() {
    // An id per row keeps a finger's press with its row when rows
    // are added or removed above it.
    list = list.push(text(row).fill_width().id(("row", index)));
}
// The id keeps this screen's scroll position its own.
SafeArea::new(ScrollView::new(list).id("orders-scroll"))
    .id("orders")
MethodWhat it does
new<M>(content: impl Into<Element<M>>) -> Container<M>A viewport around content, filling its parent.
horizontal<M>(content: impl Into<Element<M>>) -> Container<M>A viewport that scrolls sideways: a row of chips or cards wider than the screen.

Rules

  • It fills its parent, so it needs a height from above: put it in a column that fills, or directly in a SafeArea.
  • Its position belongs to its identity. Give a scroll view whose content changes an .id(..) and keep it; while a scroll view with the same id is in consecutive frames, its position is kept. One that is absent from a frame starts again at the top.
  • Content that grows leaves the position where it is. Content that shrinks under it brings it back to the new end.
  • Inside it, moving a finger more than 8 dp turns a press into a scroll.
  • The focused text input is kept in view while the keyboard is up.

Moving it from code

Ask from effects, with a ScrollTo:

fn effects(&mut self, out: &mut Effects<Message>) {
    if std::mem::take(&mut self.to_end) {
        // Carried out in the next frame, after its layout, so "the
        // end" is the end of the content that frame has.
        out.scroll(ScrollTo::end("chat").animated());
    }
}

Sideways

ScrollView::horizontal(row) scrolls a row of chips or cards that is wider than the screen. A drag is given to whichever scroll view it moves along, so a sideways row works inside a vertical screen. ADR 0037.
