Widgets/Content/Icon

Icon

One-colour vector artwork that takes its colour where it is drawn. icon(..) is short for a bare Icon::vector(..).

/// One-colour markup in the source: the path of a 24 by 24 icon.
const CHECK: VectorIcon = VectorIcon::stroked("M5 12l5 5L20 7");

/// An icon alone, an icon on a round tile, and a glyph as a stand-in.
pub fn icons<M: 'static>() -> Element<M> {
    row![
        icon(CHECK).color(ThemeColor::Success),
        Icon::vector(CHECK)
            .size(40.0)
            .round()
            .background(ThemeColor::PrimaryContainer)
            .color(ThemeColor::Primary),
        Icon::new("?").size(40.0),
    ]
    .gap(12.0)
    .cross_align(CrossAlign::Center)
    .into()
}
MethodWhat it does
new(glyph: impl Into<Cow<str>>)An icon slot showing glyph (a letter, a digit or a symbol the app's fonts contain), 40 dp square on a rounded tile.
vector(icon: VectorIcon)A vector icon, 24 dp square, in the theme's text colour, with no tile behind it.
svg(picture: &SvgPicture)An icon from a loaded SVG file (SvgPicture), 24 dp square, in the theme's text colour, with no tile behind it.
size(dp: f32)Side length in dp: of the icon itself, or of the tile when there is one (40 by default for a glyph tile, 24 for a vector icon).
radius(dp: f32)Corner radius of the tile in dp (12 by default).
round()A circular tile.
background(color: impl Into<ColorRef>)Tile colour. Gives a vector icon a tile.
bare()No tile: the glyph or icon alone.
color(color: impl Into<ColorRef>)Colour of the icon or glyph.
stroke_width(units: f32)Stroke width of a vector icon, in the icon's own view-box units (the stroke-width of its SVG), replacing the one it was defined with.

An icon says nothing to a screen reader. If it is a control, give the pressable around it a .label(..).
