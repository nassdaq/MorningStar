Widgets/Layout/Container

Container

A box: the one widget that has children, padding and decoration. Column, Row, Wrap, Stack, ScrollView, SafeArea, Pressable and Spacer, and the col!, row! and stack! macros, all produce a Container with a different preset, so every method here works on all of them. It corresponds to a frame with auto-layout in a design tool.

Paint order: shadow, background, border, then the children in order. Later children cover earlier ones.

Container::new(
    col![
        text("Samsung A15").headline(),
        text("Screen replacement").muted(),
    ]
    .gap(4.0),
)
.padding(16.0)
.radius(16.0)
.background(ThemeColor::Surface)
.border(1.0, ThemeColor::Divider)
// One of three ready-made shadows; `Shadow::new(x, y, blur, colour)`
// takes the numbers a design gives.
.shadow(elevation::MEDIUM)
.fill_width()

Creating and filling

MethodWhat it does
new(child: impl Into<Element<M>>)A box around one child.
empty()A box with no children: a coloured shape.
push(child: impl Into<Element<M>>)Adds a child after the existing ones.
push_maybe(child: Option<impl Into<Element<M>>>)Adds a child if there is one

Padding and spacing

MethodWhat it does
padding(all: f32)The same padding on all four sides, in dp.
padding_xy(horizontal: f32, vertical: f32)horizontal padding on the left and right, vertical on the top and bottom.
padding_ltrb(left: f32, top: f32, right: f32, bottom: f32)Padding per edge in the order left, top, right, bottom.
gap(dp: f32)Space between adjacent children of a row or column, in dp.
wrap()Makes a row wrap: children that do not fit on a line continue on the next, as CSS flex-wrap: wrap does.
line_gap(dp: f32)Space between the lines of a wrapping row, in dp (CSS row-gap).
safe_area(edges: SafeEdges)Adds the screen's safe-area insets on these edges to the padding.

Alignment

MethodWhat it does
main_align(align: MainAlign)How a row or column distributes its children along its own axis when there is space left over.
cross_align(align: CrossAlign)Where a row or column puts each child across its axis: vertically in a row, horizontally in a column.
content_align(anchor: Alignment)Where a stack (or a Container::new) puts its children: one of nine anchors.
center()Centres the children on both axes, whatever kind of box this is.
space_between()First child at the start, last at the end, equal space between (rows and columns).

Paint

MethodWhat it does
background(color: impl Into<ColorRef>)Fills the box with a colour.
gradient(gradient: Gradient)Fills the box with a gradient.
radial(gradient: Radial)Paints a radial gradient over the background, and over the radial gradients added before it.
radials(top_first: impl IntoIterator<Item = Radial>)Several radial gradients in CSS order, the first on top, over the background colour
blur(sigma: f32)Blurs the box's background (its colour and its radial gradients) with a Gaussian of standard deviation sigma dp
shadows(top_first: impl IntoIterator<Item = Shadow>)Several shadows in CSS order, the first on top, of either kind
radii(top_left: f32, top_right: f32, bottom_right: f32, bottom_left: f32)A radius per corner in dp, clockwise from the top-left as in CSS border-radius: 20px 20px 6px 20px, for a solid background and a solid border.
radius(dp: f32)Corner radius in dp, for the background, border, shadow and clip.
border(width: f32, color: impl Into<ColorRef>)A stroke of width dp along the inside of the box's edge.
border_dashed(width: f32, color: impl Into<ColorRef>)A dashed stroke of width dp along the inside of the box's edge, following its rounded corners
border_dash(length: f32, gap: f32)Breaks the border into dashes length dp long and gap dp apart, measured along the middle of the stroke (a design tool's "dash" and "gap").
shadow(shadow: Shadow)A drop shadow, with offsets, blur and spread in dp.
clip()Clips the children to the box, following its corner radius.

Colours, gradients and shadows explains each kind of paint.

Touch

MethodWhat it does
on_increment(message: M)What the accessibility action "increment" sends: for a value that is raised and lowered (a stepper, a slider).
on_decrement(message: M)What the accessibility action "decrement" sends.
on_press(message: M)Makes the box tappable: a tap on it delivers message to Application::update.
on_press_maybe(message: Option<M>)Like on_press, tappable only with Some.
pressed_background(color: impl Into<ColorRef>)The background while pressed.
block_touches()Swallows touches on the box so that nothing underneath it reacts: a modal scrim or a sheet over other content.

Around a text input

MethodWhat it does
input_frame()Makes this box the frame of the TextInput inside it (the first one, if there are several): a tap anywhere on the box, its padding and icons included, focuses the input.
focused_border(width: f32, color: impl Into<ColorRef>)The border while the TextInput inside has focus, replacing border.
focused_background(color: impl Into<ColorRef>)The background while the TextInput inside has focus, replacing background.

Every common modifier applies as well.
