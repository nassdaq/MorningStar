Text

Text in a step of the theme's type scale. text("..") is short for Text::new("..").

col![
    text("TSh 1,250,000").display(),
    text("Repairs").title(),
    text("Waiting for parts").headline(),
    text("The screen was replaced and tested with the customer."),
    text("SAVE").label(),
    text("Updated 08:02").caption().muted(),
]
.gap(8.0)

Creating

MethodWhat it does
new(content: impl Into<Cow<str>>)Text from a literal or a String.
rich<S: Into<Span>>(spans: impl IntoIterator<Item = S>)Text made of several Spans, each of which may have its own weight, colour or font family: a sentence with a bold or coloured phrase in it.

A &'static str or a String also becomes a text wherever a widget is expected.

The type scale

MethodWhat it does
role(role: TextRole)Uses a step of the theme's type scale (size, weight and line height).
display()The one big number or word on a screen.
title()A screen title.
headline()A section or card heading.
body()Running text. The default.
label()Button, tab and field labels.
caption()Metadata, timestamps and hints.

Size, weight, colour and family

MethodWhat it does
size(dp: f32)Font size in dp, overriding the role's.
weight(weight: TextWeight)Font weight, overriding the role's.
regular()Regular weight (400).
medium()Medium weight (500).
semibold()Semibold weight (600).
bold()Bold weight (700).
color(color: impl Into<ColorRef>)Text colour: a Color or a ThemeColor.
muted()The theme's secondary text colour.
family(family: impl Into<FontFamily>)The font family, overriding the theme's choice for the text's role (see Fonts)
italic()Sets the text in italics (CSS font-style: italic).

Lines

MethodWhat it does
align(align: TextAlign)Alignment of the lines within the text's own box.
centered()Centres the lines within the text's box.
line_height(multiple: f32)Line height as a multiple of the font size, overriding the role's.
line_height_dp(dp: f32)Line height in dp, as CSS and design tools usually give it (line-height: 22px), overriding the role's.
letter_spacing(dp: f32)Extra space after every character, in dp (CSS letter-spacing, a design tool's "letter spacing" in pixels).
tabular_nums()Sets digits on a common width, so that columns of numbers line up and a running timer keeps still (CSS font-variant-numeric: tabular-nums).
uppercase()Shows the text in capitals (CSS text-transform: uppercase).
max_lines(lines: u32)Shows at most this many lines; the rest is cut off (there is no ellipsis yet).

Alignment shows only when the text is wider than its words, so give an aligned text a width.

Effects

MethodWhat it does
shadow(x: f32, y: f32, color: impl Into<ColorRef>)A hard shadow: the same text drawn once more behind it, moved by (x, y) dp, in color (CSS text-shadow: 3px 3px 0 #fff).
outline(width: f32, color: impl Into<ColorRef>)Outlines the letters with a stroke width dp wide, centred on their edges, over the fill (CSS -webkit-text-stroke: 1.5px #fff).

Several styles in one text

col![
    text("Order 1042")
        .size(22.0)
        .semibold()
        .letter_spacing(-0.3)
        .line_height_dp(28.0),
    // One text, three styles: spans share the line breaking.
    Text::rich([
        span("By continuing you accept the "),
        span("terms of service").bold().color(ThemeColor::Primary),
        span("."),
    ])
    .muted()
    .fill_width(),
    // Digits on a common width, so a column of amounts lines up.
    text("12,400.00").tabular_nums(),
    // At most two lines; the rest is cut off.
    text("A long note that the customer wrote when the phone was handed in.")
        .max_lines(2)
        .fill_width(),
]
.gap(8.0)
.fill_width()
MethodWhat it does
new(content: impl Into<Cow<str>>)A span in the style of the text it is part of.
italic()Sets this span in italics (CSS font-style: italic, an <em>).
weight(weight: TextWeight)Font weight of this span.
regular()Regular weight (400).
medium()Medium weight (500).
semibold()Semibold weight (600).
bold()Bold weight (700).
color(color: impl Into<ColorRef>)Colour of this span: a Color or a ThemeColor.
family(family: impl Into<FontFamily>)Font family of this span.

Spans share the text's line breaking, so a bold phrase in the middle of a sentence wraps with it.
