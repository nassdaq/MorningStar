TextInput

An editable text. It shows the value it is given and delivers each new value as a message; it has no frame of its own.

fn phone_field(&self) -> Element<Message> {
    // The input is only its text. The box around it is the field:
    // its height, padding, border, and its look while focused.
    row![
        TextInput::new(self.phone.clone())
            .placeholder("0712 345 678")
            .keyboard(KeyboardType::Phone)
            .action(ImeAction::Next)
            .max_length(13)
            // The application owns the string: every change arrives
            // as a message, and `update` stores it.
            .on_input(Message::Phone)
            .semantic_label("Phone number")
            // Focus stays with the field when the screen changes.
            .id("phone")
            .fill_width(),
    ]
    .height(52.0)
    .cross_align(CrossAlign::Center)
    .padding_xy(16.0, 0.0)
    .radius(12.0)
    .border(1.0, ThemeColor::Divider)
    .focused_border(2.0, ThemeColor::Primary)
    // A tap anywhere in the box focuses the input inside it.
    .input_frame()
    .fill_width()
    .into()
}

Value and messages

MethodWhat it does
new(value: impl Into<String>)A single-line field showing value, in the theme's body text.
placeholder(text: impl Into<Cow<str>>)Shown, in the placeholder_color, while the value is empty.
placeholder_color(color: impl Into<ColorRef>)Colour of the placeholder (the theme's muted text by default).
on_input(message: impl Fn(String) -> M + Send + Sync + 'static)The message for a new value.
on_submit(message: M)The message delivered when the keyboard's action key (Done, Go, Search, Send) is pressed.

The keyboard

MethodWhat it does
secure(secure: bool)A password: each character is shown as a bullet, and the keyboard neither learns nor suggests.
keyboard(keyboard: KeyboardType)Which keyboard to show.
capitalization(capitalization: Capitalization)What the keyboard capitalises by itself (nothing by default).
action(action: ImeAction)The keyboard's action key
no_autocorrect()Turns the keyboard's correction and suggestions off (they are on by default, and always off for a secure field): for names, codes and references.

What the value may hold

MethodWhat it does
multiline()Several lines: the text wraps at the field's width, the field grows downwards with it, and the Return key inserts a line break.
max_lines(lines: u32)For a multiline field: it grows to at most this many lines and then scrolls inside itself.
max_length(characters: usize)Most characters the value may hold.
digits_only()Keeps only the digits 0 to 9 of whatever is typed or pasted by the keyboard.
auto_advance()For one field of a row of code boxes, with max_length: when the field becomes full, focus moves to the next TextInput; backspace in an empty field moves to the previous one and deletes there; and a character typed into a full field replaces the one it holds.

Style

MethodWhat it does
style(text: Text)Takes size, weight, line height, colour, alignment, family and letter spacing from a Text (its content is ignored), so a field can share a design's text style helper
role(role: TextRole)Uses a step of the theme's type scale; see Text::role.
size(dp: f32)Font size in dp.
weight(weight: TextWeight)Font weight.
color(color: impl Into<ColorRef>)Colour of the value (the theme's text colour by default).
caret_color(color: impl Into<ColorRef>)Colour of the caret (the theme's primary colour by default).
family(family: impl Into<FontFamily>)The font family; see Text::family.
line_height(multiple: f32)Line height as a multiple of the font size.
line_height_dp(dp: f32)Line height in dp.
letter_spacing(dp: f32)Extra space after every character, in dp.
align(align: TextAlign)Where the text sits in the field.

The box around it

These are methods of the Container that holds the input:

MethodWhat it does
input_frame()Makes this box the frame of the TextInput inside it (the first one, if there are several): a tap anywhere on the box, its padding and icons included, focuses the input.
focused_border(width: f32, color: impl Into<ColorRef>)The border while the TextInput inside has focus, replacing border.
focused_background(color: impl Into<ColorRef>)The background while the TextInput inside has focus, replacing background.
