Picture and Avatar

Picture

A picture draws an image, a multi-colour vector picture, or a loaded SVG file.

/// An app with one photograph, decoded once at setup.
#[derive(Default)]
pub struct Gallery {
    photo: Option<Image>,
}

impl Application for Gallery {
    type Message = ();

    fn setup(&mut self, setup: &mut Setup<'_>) {
        // Four pixels stand in for `include_bytes!("../assets/photo.png")`
        // with `setup.add_image_png(..)`.
        let pixels = [255, 255, 255, 255].repeat(4);
        self.photo = setup.add_image_rgba8(2, 2, &pixels).ok();
    }

    fn view(&self) -> Element<()> {
        match self.photo {
            // Cropped to fill a rounded 16:9 box.
            Some(photo) => Picture::new(photo)
                .fit(ImageFit::Cover)
                .radius(16.0)
                .fill_width()
                .aspect_ratio(16.0 / 9.0)
                .into(),
            // An avatar falls back to initials when there is no image.
            None => Avatar::new("Amina Juma").image_maybe(self.photo).into(),
        }
    }

    fn update(&mut self, _message: ()) {}
}
MethodWhat it does
new(image: Image)A picture of image.
vector(picture: VectorPicture)A multi-colour vector picture.
svg(picture: &SvgPicture)A picture loaded from an SVG file
fit(fit: ImageFit)How the image fills a box of a different shape.
radius(dp: f32)Corner radius in dp. Half the side of a square picture gives a circle.
tint(color: impl Into<ColorRef>)Multiplies every pixel by a colour: white with an alpha of 0.5 draws the image half transparent; a colour recolours an icon drawn in white.

ImageFit says how the image fills a box of a different shape: Cover crops, Contain shows it whole.

Images are added once, at setup, from PNG data (setup.add_image_png(bytes)) or raw pixels (setup.add_image_rgba8(width, height, pixels)). Only PNG is decoded.

An SVG file

/// An SVG file of the app, parsed once, the first time it is drawn.
static LOGO: SvgAsset = SvgAsset::new(
    r##"<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24">
        <circle cx="12" cy="12" r="10" fill="#E3AE3A"/>
        <path d="M7 12l3.5 3.5L17 9" fill="none" stroke="#141005" stroke-width="2"/>
    </svg>"##,
);

/// The file as a picture, in its own colours.
pub fn logo<M: 'static>() -> Element<M> {
    Picture::svg(LOGO.get()).width(96.0).height(96.0).into()
}

An SvgAsset is parsed once, the first time it is drawn. The loader accepts a static subset of SVG and refuses anything else with the line it is on; see Text, fonts and pictures.

Avatar

A person: an image cropped to a circle, or initials when there is none.

MethodWhat it does
new(name: &str)An avatar for a person called name: "Amina Juma" shows "AJ".
size(dp: f32)Diameter in dp (40 by default).
image(image: Image)Shows this image, cropped to the circle, instead of the initials.
image_maybe(image: Option<Image>)Like image when there may be none: the initials are the fallback.
background(color: impl Into<ColorRef>)Circle colour.
color(color: impl Into<ColorRef>)Colour of the initials.
