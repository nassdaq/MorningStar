Column, Row and Wrap

A column arranges its children top to bottom, a row side by side. Most screens are columns and rows nested inside each other.

col![
    text("Summary").headline(),
    row![
        // Two fills share the row two to one.
        Container::new(text("Paid"))
            .padding(12.0)
            .background(ThemeColor::Surface)
            .fill_width_weight(2.0),
        Container::new(text("Due"))
            .padding(12.0)
            .background(ThemeColor::SurfaceVariant)
            .fill_width_weight(1.0),
    ]
    .gap(8.0)
    .fill_width(),
    // A spacer takes what is left, pushing the button to the bottom.
    Spacer::new(),
    Button::new("Continue").fill_width(),
]
.gap(16.0)
.padding(20.0)
.fill()

Creating one

WriteFor
col![a, b, c]A column with these children
row![a, b, c]A row with these children
Column::new(), Row::new()An empty one, filled with .push(..) in a loop
Wrap::new()A row whose children continue on the next line

Each returns a Container, so padding, gap, alignment, paint and touch are the container's methods.

Spacing and alignment

MethodWhat it does
gap(dp: f32)Space between adjacent children of a row or column, in dp.
wrap()Makes a row wrap: children that do not fit on a line continue on the next, as CSS flex-wrap: wrap does.
line_gap(dp: f32)Space between the lines of a wrapping row, in dp (CSS row-gap).
main_align(align: MainAlign)How a row or column distributes its children along its own axis when there is space left over.
cross_align(align: CrossAlign)Where a row or column puts each child across its axis: vertically in a row, horizontally in a column.
center()Centres the children on both axes, whatever kind of box this is.
space_between()First child at the start, last at the end, equal space between (rows and columns).

A child overrides the parent's cross-axis placement with .align_self(..).

Sharing the space

Children that fill share what is left along the axis, by weight:

row![
    // Fixed: exactly 48 by 48 dp.
    Container::empty()
        .size(48.0, 48.0)
        .radius(12.0)
        .background(ThemeColor::PrimaryContainer),
    // Fill: takes the width the row has left, so this is the text
    // that wraps when the screen is narrow.
    text("Fundi wa simu, Kariakoo").fill_width(),
    // Hug (the default): as wide as its words.
    text("08:02").caption().muted(),
]
.gap(12.0)
.cross_align(CrossAlign::Center)
.fill_width()

Wrapping onto new lines

let mut chips = Wrap::new().gap(8.0).line_gap(8.0).fill_width();
for tag in tags {
    chips = chips.push(
        Container::new(text(*tag).label())
            .padding_xy(12.0, 6.0)
            .radius(999.0)
            .border(1.0, ThemeColor::Divider),
    );
}

.gap(..) is the space between neighbours on a line and .line_gap(..) the space between lines.

Long lists. A column builds every child each frame. That is what the example apps do for lists of tens of rows. There is no widget that builds rows only as they scroll into view.
