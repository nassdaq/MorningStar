Widgets/Content/Divider

Divider

A line between rows, in the theme's divider colour.

col![
    text("Inbox"),
    Divider::new(),
    text("Drafts"),
    // Starts 56 dp in, level with the text beside an avatar.
    Divider::new().inset(56.0),
    text("Sent"),
]
.gap(12.0)
.fill_width()
MethodWhat it does
new()A horizontal divider.
vertical()A vertical divider, for rows: 1 dp wide, filling the height.
thickness(dp: f32)Thickness in dp.
inset(dp: f32)Leaves dp clear at the leading end (left of a horizontal divider, top of a vertical one), so the line starts where a row's text does.
color(color: impl Into<ColorRef>)Line colour.

A horizontal divider fills the width of its parent and is 1 dp thick unless told otherwise. Divider::vertical() is for rows: 1 dp wide, filling the height.
